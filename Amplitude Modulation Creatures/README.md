# Amplitude Modulation Creatures

Sinh vật hữu cơ sinh ra từ điều biến biên độ (amplitude modulation) — hình khối uốn lượn, biến dạng liên tục, phản ứng theo âm thanh.

Organic creatures generated through amplitude modulation — writhing, continuously deforming forms that react to sound.

## Cách dùng / How to use

1. Tải file `.toe` về (nút **Download raw file**, đừng dùng Save link as).
2. Mở bằng TouchDesigner.
3. Chỉnh các tham số ở node điều khiển để đổi hình dạng, tốc độ và độ biến dạng của sinh vật.

Patch không cần media ngoài — mở là chạy.
