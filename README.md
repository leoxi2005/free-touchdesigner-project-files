## Cách tải / How to download

**Một file:** mở thư mục project → bấm vào file `.toe` → nút **Download raw file**.

**Tất cả:** nút xanh **Code** ở đầu trang → **Download ZIP**.

Hoặc bằng dòng lệnh:

```bash
git clone https://github.com/leoxi2005/free-touchdesigner-project-files.git
```

> ⚠️ Đừng bấm chuột phải → Save link as trên trang GitHub thường — bạn sẽ tải về file HTML. Phải dùng nút **Download raw file**.

## Yêu cầu / Requirements

- [TouchDesigner](https://derivative.ca/download) — bản **Non-Commercial** (miễn phí) mở được hết.
- Các file được lưu bằng **TouchDesigner 2025.33230** trên macOS. Bản TD cũ hơn có thể không mở được; bản mới hơn thì ổn.
